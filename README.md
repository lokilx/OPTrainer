OPTrainer 1.3.6

Professional trainer for The Binding of Isaac: Repentance+ using REPENTOGON latest stable.

Hotkeys

- F6: OP BUILD
- F7: GOD
- F8: MENU
- F9: HEAL
- F10: KILL ROOM

All hotkeys are configurable in Settings.

Features

- Responsive compact UI with icon tabs and fixed-width controls.
- Quick Actions and Quick Builds.
- Favorites for builds, collectibles, trinkets, cards, and pills.
- Cached search by name, item ID, type, and quality.
- Notification queue with duplicate suppression.
- Safer config loading and save migration.
- Debug timing mode.
